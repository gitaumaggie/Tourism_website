NAIROBI UNLOCKED 🇰🇪
Discover Nairobi. Experience Kenya. Make memories.
My First Website Development Project

1. Introduction

Nairobi Unlocked is a travel and tourism website designed to introduce visitors to the beauty, culture, history, wildlife and experiences of Nairobi, Kenya.
The idea behind this project was to create a simple, visually engaging and user-friendly platform where travellers can discover interesting places to visit, learn about local experiences and get inspiration for their next adventure.
Nairobi is more than just a capital city. It is a destination where modern city life meets rich cultural heritage, incredible wildlife, beautiful natural spaces and diverse cuisine. I wanted to bring these experiences together in one digital space.
This project is particularly meaningful to me because it is my first complete website development project. As a Kenyan and a Software Engineering student, I wanted to create something that reflects my interests while allowing me to put my frontend development knowledge into practice.
The idea, choice of destination, website concept, five main themes and overall project architecture were developed by me. I also explored different design approaches to create an enjoyable experience for visitors.

2. Project Objectives

The main objective of Nairobi Unlocked is to make discovering Nairobi easier and more exciting for travellers.
The project aims to:
Promote Nairobi as an interesting tourist destination.
Showcase Kenya's cultural heritage, wildlife, history and cuisine.
Help visitors discover attractions and recreational activities.
Provide photographs and short descriptions that make destinations easier to explore.
Direct visitors to relevant external tourism resources for additional information.
Create a responsive website that can be accessed on different screen sizes.
Apply fundamental HTML, CSS and JavaScript concepts in a practical project.

3. The Five Main Themes

The website is organised around five major themes that represent different aspects of the Nairobi experience.
3.1 Culture
This section introduces visitors to Kenya's creativity, traditions and cultural identity.
One of the main attractions featured is the Maasai Market, where visitors can discover handmade jewellery, colourful beadwork, traditional artefacts, paintings and unique souvenirs.
3.2 Nature and Wildlife
This theme highlights Nairobi's incredible wildlife experiences.
A major attraction is the Giraffe Centre, where visitors can encounter endangered Rothschild's giraffes and learn about wildlife conservation.
3.3 History
This section introduces visitors to Kenya's historical and natural heritage.
Featured destinations include:
Nairobi National Museum.
Nairobi Snake Park.
Visitors can discover Kenya's history, cultural heritage and fascinating wildlife.
3.4 Recreation
This theme focuses on outdoor activities and recreational experiences.
Karura Forest is one of the featured destinations, offering visitors opportunities to cycle, walk, enjoy nature and explore its beautiful surroundings.
3.5 Food
Food is an important part of experiencing a destination.
This section introduces visitors to traditional Kenyan dishes, including:
Mukimo.
Ugali.
Nyama Choma.
Other traditional Kenyan meals and local favourites.
The intention is to celebrate Kenya's food culture and encourage visitors to experience local cuisine.
Beyond Nairobi: Maasai Mara
Although the primary focus is Nairobi, I also included a destination beyond the city: the Maasai Mara.
This section introduces the famous hot-air balloon safari experience, giving visitors a glimpse of another unforgettable Kenyan adventure.
It is presented separately so that visitors can distinguish attractions within Nairobi from experiences elsewhere in Kenya.

4. Website Pages and Features

The website consists of four main pages.
4.1 Home Page – index.html
The homepage introduces visitors to Nairobi Unlocked.
Its main features include:
Nairobi Unlocked branding with the Kenyan flag.
An introductory hero video that automatically plays and loops.
A short welcome message introducing Nairobi.
Five main tourism themes.
Attractive photographs representing different experiences.
Short descriptions of the featured destinations.
Explore links directing visitors to the relevant sections of the Explore page.
A traveller review section.
A footer containing navigation links and website information.
The objective is to capture visitors' attention through visual storytelling while keeping the information concise and easy to navigate.
4.2 Explore Page – explore.html
The Explore page provides more detailed information about the destinations introduced on the homepage.
It contains separate sections for:
Culture and Maasai Market.
Nature and Wildlife, featuring the Giraffe Centre.
History, featuring the National Museum and Snake Park.
Recreation, featuring Karura Forest.
Food, showcasing traditional Kenyan cuisine.
Maasai Mara, featuring hot-air balloon safaris.
Each section contains relevant photographs and short descriptions to help visitors understand what they can experience at each destination.
4.3 About Page – about.html
The About page introduces the person behind the project.
It includes my biography, educational background, interests and skills.
Technical skills:
Frontend Development.
UI/UX Design.
Linux.
Python.
Soft skills:
Communication.
Time Management.
Public Speaking.
The page also includes my profile photograph and contact information.
4.4 Contact Page – contact.html
The Contact page provides visitors with a simple way to make enquiries.
The contact form includes:
Full name.
Email address.
Phone number (optional).
Destination or experience of interest.
Expected travel date (optional).
Message.
Mandatory fields are validated before submission.
JavaScript is used to display an acknowledgement message after a successful form submission.
The current form demonstrates frontend validation and submission feedback. It does not yet connect to a backend or email service, so enquiries are not actually transmitted or stored.

6. User Experience and Design Decisions

One of my main considerations when developing Nairobi Unlocked was the user experience.
I wanted the website to be visually attractive without overwhelming visitors with excessive text, complicated navigation or unnecessary design elements.
Some of the design decisions included:
Using large photographs to showcase destinations.
Keeping descriptions short and informative.
Maintaining a consistent colour palette.
Using a shared external stylesheet across the pages.
Making navigation straightforward.
Designing layouts that adapt to different screen sizes.
Including a dark and light mode option.
Using a hero video to create an engaging first impression.
The overall design inspiration came from exploring tourism websites, particularly Mauritius Now (https://mauritiusnow.com/).
I appreciated its use of videos, large destination photographs and clear content sections. I used these observations as inspiration while developing a distinct visual identity for Nairobi Unlocked.

8. Running the Project Locally

To view Nairobi Unlocked locally:
Clone or download the GitHub repository.
Open the project folder in Visual Studio Code.
Ensure the project files and media folder remain in their correct locations.
Open the terminal in the project directory.
Run the following command:
python3 -m http.server 8080

Open a browser and visit:
http://127.0.0.1:8080/index.html
The website can be explored locally through the Home, Explore, About and Contact pages.

10. Learning Experience and Future Improvements

As my first website development project, Nairobi Unlocked has been an important learning experience.
It has allowed me to move beyond learning individual HTML tags, CSS properties and JavaScript concepts and start thinking about how different components work together to create a complete user experience.
Some of the areas I have explored include:
Structuring multi-page websites.
Linking pages through navigation.
Managing image and video resources.
Using external stylesheets and JavaScript files.
Creating responsive layouts.
Understanding the relationship between HTML, CSS and JavaScript.
Identifying and troubleshooting broken file paths and server configuration issues.
Considering accessibility and usability when designing interfaces.
There are still several improvements I would like to make in future versions:
Integrate a backend to receive and store visitor enquiries.
Include verified tourism links, updated attraction prices and opening hours.
Add more destination information and travel recommendations.
Introduce interactive maps to help visitors locate attractions.
Improve the traveller review section with genuine visitor feedback.
Deploy the website publicly so that it can be accessed by travellers beyond my local development environment.
I see Nairobi Unlocked as a starting point rather than a finished commercial tourism platform. It represents my first attempt at combining creativity, technology and a personal interest in promoting Kenya.
